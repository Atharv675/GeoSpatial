# Phase 2 — Sentinel Ingestion

## Purpose

Ingest **curated only** Sentinel-1 GRD and Sentinel-2 L2A assets for configured AOIs, with secure handling, checksum validation, and STAC-compatible registry entries.

## Components

| Module | Role |
|--------|------|
| `ingestion/aoi.py` | Load `data/registry/aois.json` (max 3 AOIs) |
| `ingestion/manifest.py` | Load `curated_manifest.json`, 30-day filter |
| `ingestion/download.py` | Local copy + HTTPS resumable download |
| `ingestion/metadata.py` | STAC Item construction |
| `ingestion/sentinel1.py` | Sentinel-1 GRD ingest |
| `ingestion/sentinel2.py` | Sentinel-2 L2A ingest |
| `ingestion/ingest.py` | Orchestrator + `ingest_state.json` |
| `pipeline/ingest.py` | Pipeline step wrapper |

## Configuration files

- `data/registry/aois.json` — 2 demo AOIs (expandable to 3)
- `data/registry/curated_manifest.json` — curated asset list (generated by seed script)

## Seed curated data

```bash
python scripts/seed_curated_data.py
```

Creates placeholder `.tif` payloads under `data/raw/curated/` and writes checksums into the manifest. Dates are relative to UTC now (within 30-day scope).

## Run ingestion

```bash
# Pipeline step
python -m backend.pipeline.run_pipeline

# Or API
curl -X POST http://localhost:8000/api/v1/ingestion/run

# Or Python
python -c "from backend.ingestion import run_ingestion; run_ingestion()"
```

## API endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/aois` | GeoJSON FeatureCollection |
| GET | `/api/v1/aois/{aoi_id}` | Single AOI |
| GET | `/api/v1/ingestion/manifest` | Manifest summary |
| GET | `/api/v1/ingestion/status` | Last run status |
| POST | `/api/v1/ingestion/run` | Run ingestion |

## Remote assets

Manifest entries may use HTTPS `remote` sources:

```json
"source": {
  "type": "remote",
  "url": "https://…",
  "checksum_sha256": "…"
}
```

- SSL verification enabled (never disabled)
- Resumable via `.part` + `.download.json` state
- Checksum verified after download

## Security

- HTTPS-only remote URLs
- Path traversal blocked via `safe_join`
- Checksum required for all assets
- No shell execution; httpx only
- AOI/asset IDs validated with strict patterns

## Phase 3 integration

- `data/raw/sentinel-1-grd/{aoi_id}/{YYYYMMDD}/`
